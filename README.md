# 纸卡 · Paper Cards

一个简单、轻量的学习闪卡工具。

把需要记忆的内容做成一张张“纸卡”，通过反复复习帮助你记住单词、知识点、公式和其他学习内容。

## ✨ 你可以用它做什么

- 📚 **制作学习卡片**：为每张卡片设置正面和背面内容。
- 🔄 **顺序切换**：可以在“正面 → 背面”和“背面 → 正面”之间切换。
- 🧠 **间隔复习**：根据自己的掌握情况进行复习和记录。
- 📷 **拍照识别**：通过 OCR 从图片中提取文字，快速制作卡片。
- 📥 **批量导入**：一次导入多条内容，减少重复输入。
- 📊 **学习记录**：记录复习情况，方便查看自己的学习进度。
- 💾 **数据备份**：支持导出和导入学习数据。
- ☁️ **云端同步**：登录账号后，可以在不同设备之间同步自己的卡片和学习数据。
- 📱 **手机使用**：支持在手机浏览器中使用，也可以添加到手机主屏幕。

## 📝 怎么使用

### 1. 创建卡片

打开纸卡后，可以直接添加新的卡片。

你可以手动输入内容，也可以使用图片识别或批量导入功能。

例如：

| 正面 | 背面 |
| --- | --- |
| Innovation | 创新 |
| Abel 判别法 | 幂级数收敛性判别方法 |
| 特征值 | 矩阵特征方程的根 |

### 2. 开始复习

进入学习模式后，先尝试回忆卡片另一面的内容，再查看答案。

根据自己的掌握情况进行评价，纸卡会记录你的复习情况。

### 3. 管理卡片

你可以根据需要添加、编辑和删除卡片，也可以使用分类和筛选功能整理不同的学习内容。

## ☁️ 登录与同步

如果你希望在多个设备之间使用同一份学习数据，可以使用“登录同步”功能。

登录后：

- 卡片数据可以同步到云端。
- 在其他设备登录同一个账号后，可以继续使用自己的学习内容。
- 本地数据和云端数据进行同步时，应用会提示你选择需要保留的数据。

如果只在一台设备上使用，也可以不登录。

## 💾 数据备份

建议定期使用“导出备份”保存自己的学习数据。

这样即使更换设备，也可以通过导入备份恢复学习内容。

## 📱 手机上使用

纸卡可以直接在手机浏览器中打开。

如果浏览器支持 PWA，可以将纸卡添加到手机主屏幕，之后像普通 App 一样打开。

## 🔒 关于你的数据

登录同步功能用于保存和同步你的学习数据。

如果你不使用账号同步，学习数据可以保存在当前设备上。

请定期备份重要的学习内容。

## 💡 适合哪些人？

纸卡适合需要反复记忆内容的学习场景，例如：

- 英语单词和短语
- 专业课知识点
- 数学公式
- 考试重点
- 编程语法
- 需要长期记忆的任何内容

## 🌱 关于纸卡

纸卡希望把“整理知识 → 反复回忆 → 逐渐掌握”这件事做得简单一点。

不需要复杂的学习系统，只需要一张卡、一点时间，以及一次次主动回忆。

**祝你学习顺利。**
